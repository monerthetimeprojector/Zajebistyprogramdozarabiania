# Zajebistyprogramdozarabiania
To program termux który zrobiłem bo tak pzdrr okt.
Zaawansowany Google Maps Lead Scraper - szuka firm bez strony WWW, filtruje je i przygotowuje gotowe cele pod Lovable/WebDev.

## 🔥 Funkcje
- **Lean Skid Vibe Menu** (ASCII art, purple/green terminal aesthetic)
- **Wbudowany Proxy Scraper & Checker** (Omija zabezpieczenia Google, testuje proxy w locie)
- **Filtrowanie wyników** (Tylko biznesy BEZ podpiętej witryny)
- **Automatyczny zapis na telefonie** (Zapisuje listę w formacie .txt prosto do folderu pobrane)

## 🛠️ Instalacja (Termux / Android)

1. Aktualizacja środowiska i instalacja Pythona, Gita oraz bibliotek do parsowania:
`pkg update && pkg upgrade -y`
`pkg install python git libxml2 libxslt -y`

2. Zezwolenie Termuxowi na zapis w telefonie (Zrób to, żeby pliki spadały na Twój "Pulpit"):
`termux-setup-storage`
*(Potwierdź na ekranie telefonu!)*

3. Pobranie repozytorium:
`git clone https://github.com/TWOJA_NAZWA_UZYTKOWNIKA/Zajebistyprogramdozarabiania.git`

4. Wejście i instalacja modułów Pythona:
`cd Zajebistyprogramdozarabiania`
`pip install -r requirements.txt`

## 🚀 Uruchomienie

Aby wejść do matrixa:
`python main.py`
